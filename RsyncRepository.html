This builds a suggested command; it doesn't run anything. Use it as a starting point and edit before running, and do a dry run first, especially when deleting. Rsync is a Unix tool; on Windows it needs WSL, Git Bash or cwRsync. Less common options (daemon config, batch files, fuzzy matching, checksum choices, fine-grained filters) are left out; see man rsync.
